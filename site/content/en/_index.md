# Neport

Neport brings project tasks, work sessions, and daily reports together for teams.

## Features

- Project and ticket management
- Kanban, WBS, and Gantt views
- Work-session and daily-report tracking
- Workflows, approvals, and audit logs

For developers, see the [API documentation](developer/api/).
