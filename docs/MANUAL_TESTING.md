# ブラウザでの動作確認

[クイックスタート](../README.md#クイックスタート)に沿って試験環境を起動し、初回管理者と一般ユーザーを用意する。変更に関係する行を選んで確認する。APIの詳細な回帰確認には[バックエンドのテスト](../backend/tests/)を使う。

| 領域 | 確認する操作と結果 |
| --- | --- |
| ログイン・権限 | 未ログインで保護ページを開くとログイン画面に移る。ログイン後は再読み込みしてもセッションが続き、ログアウト後は保護ページを再び開けない。メンバーを指定した案件を所属者と非所属者で開き、閲覧結果に差が出る。 |
| 案件とチケット | 案件を作り、親子チケット・担当・期限を設定する。ツリーの展開、担当・期限の絞り込み、ページ移動で対象を見つけられる。進行中の担当票は本人のダッシュボードに表示される。 |
| WBS・ガント | WBSのセル編集や親の付け替えを保存し、再表示で値が残ることを確認する。日程と依存を設定し、ガントに反映されることを確認する。循環する依存の追加では更新されず、エラーが見える。 |
| カンバン | 許可された列への移動が詳細にも反映される。許可外の遷移や一般メンバーによる確認済みへの移動では共有状態が変わらない。 |
| 稼働・日報 | 同じ日に開始・終了を2回繰り返し、月次一覧の区間と合計を確認する。日報にその日の操作票が集まり、提出後に月次一覧の状態が更新される。 |
| アカウント設定 | 言語切替が主要画面に反映され、再ログイン後も維持される。パスワード変更後に別ブラウザの旧セッションが失効する。 |
